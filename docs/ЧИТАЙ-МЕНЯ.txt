RATNET VPN — портативная версия для Windows
===========================================

Запуск: двойной клик по RatnetVPN.exe
Устанавливать ничего не нужно, Python не требуется. Все настройки —
только в памяти программы, на диск ничего не пишется.


ЧТО В ПАПКЕ
-----------
RatnetVPN.exe   — сама программа (один файл, ~16 МБ)
scripts\        — скрипты, которые программа загружает на серверы:
                  01-ru-entry.sh      развернуть вход (Россия)
                  02-foreign-node.sh  подготовить иностранную ноду
                  03-join-node.sh     подключить ноду к входу
                  04-client-block.sh  блокировка/разблокировка клиента
                 05-cleanup.sh       возврат сервера в исходное состояние
                  Можно править без пересборки exe: если папка есть рядом
                  с exe, берётся именно она. Если удалить — программа
                  возьмёт встроенную копию.


ВКЛАДКА «СЕРВЕРЫ»
-----------------
Слева — вход (Россия), справа — выход (иностранная нода).

1. Впиши IP, пользователя, ключ (файл) или пароль.
   Кнопка «Проверить связь» — покажет имя сервера и версию системы.
2. Вход: выбери транспорт (reality / tls / hysteria2), порт, домен-маскировку.
   Блокировка рекламы: кнопка «Переключить» и индикатор рядом (вкл / выкл,
   по умолчанию выключено). Кнопка «Развернуть вход» переустанавливает вход
   (старый конфиг уходит в бэкап).
3. Выход: тег, часовой пояс, галочки «Блокировка рекламы на ноде»
   и «Ребут Пн/Ср/Пт в 05:00».
   «Подготовить ноду» → в журнале появится токен соединения.
   «Соединить с входом» → нода добавляется в балансировщик и проверяется
   живым подключением.
4. Внизу — журнал. Строки появляются сразу, по мере выполнения: видно, на каком
   шаге скрипт, и если что-то зависло — понятно, где именно.

Блокировка рекламы по умолчанию выключена. Кнопка «Переключить» включает и
выключает правило на уже настроенном входе, без переустановки. Индикатор рядом
показывает состояние, в журнале появляется «Включено» или «Выключено».


ВКЛАДКА «КЛИЕНТЫ»
-----------------
«Обновить» — список клиентов, расход и лимиты.
«Создать клиента» — имя и лимит в ГБ (0 = без лимита). Готовая ссылка
появится внизу, кнопка «Копировать ссылку» кладёт её в буфер обмена.
«Удалить», «Сбросить лимит», «Ссылка» — работают с выбранной строкой.

БЛОКИРОВКА ДОСТУПА
──────────────────
«Блокировать» — отключает VPN выбранному человеку:
  • убирает его из работающего сервиса без перезапуска (остальные не замечают);
  • запоминает его UUID, чтобы можно было вернуть того же клиента.
«Разблокировать» — возвращает доступ с ПРЕЖНИМ UUID: ссылка и профиль
на устройстве продолжают работать, менять ничего не нужно.
Заблокированный клиент остаётся в таблице со статусом «заблокирован».

Внизу окна: транспорт входа, суммарный трафик за всё время, активные сервисы.

ОЧИСТКА СЕРВЕРА
───────────────
Кнопки «Очистить вход…» (слева) и «Очистить выход…» (справа) возвращают
сервер в состояние «до Ratnet VPN».

Как это работает:
  1. Приложение показывает СПИСОК того, что будет удалено, с размерами
     (журнал внизу), ничего не меняя.
  2. Спрашивает подтверждение и требует ввести слово Yes.
     Не введено — операция отменяется.
  3. Перед удалением делает бэкап: /root/ratnet-cleanup-<дата>.tar.gz

Удаляется: Xray с конфигами и geo-файлами, службы xray / vpn-quota /
vpn-traffic-log / singbox-h2, наши скрипты, учёт трафика и квоты,
расписание ребутов, nodes.txt, строки cron.

НЕ трогается: docker и AmneziaWG, nginx, node_exporter, resume-web,
системные пакеты, правило 22/tcp, пользователи xray/singbox.

Откат: tar -xzf /root/ratnet-cleanup-<дата>.tar.gz -C / && systemctl daemon-reload
затем systemctl enable --now xray

Внимание: после очистки профили клиентов перестают работать.

БУФЕР ОБМЕНА
────────────
Вставить IP в поле: Ctrl+V или правая кнопка → «Вставить».
Выделить всё в поле: Ctrl+A.
В журнале: выдели мышью нужное и нажми Ctrl+C, либо правая кнопка →
«Копировать строку» (двойной клик по слову — выделить слово).
Скопированное не пропадает после закрытия программы.


ВАЖНО ЗНАТЬ
-----------
• Приложение подключается по SSH от root — оно меняет конфиги сервисов.
• Пароли и ключи не сохраняются: закрыл программу — они забыты.
• Хост-ключи серверов принимаются автоматически (как ssh -o
  StrictHostKeyChecking=no). Если нужна строгая сверка отпечатков — скажи.
• Токен соединения (шаг 3) содержит ключи доступа к ноде — не пересылай.
• При транспорте hysteria2 пофамильные лимиты и статистика не работают:
  все клиенты приходят во вход одним транзитным пользователем.
  Маршрутизация и блокировка рекламы работают.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
Ошибки выполнения видны в журнале внизу окна.
Если программа упала при запуске — рядом появится отчёт:
  %TEMP%\ratnet-crash.log

Проверка целостности сборки (из командной строки):
  RatnetVPN.exe --selftest
Результат: %TEMP%\ratnet-selftest.txt

Работа из командной строки (то же самое без интерфейса):
  RatnetVPN.exe --host 1.2.3.4 --key C:\Users\me\.ssh\id_vpn status
  RatnetVPN.exe --host 1.2.3.4 --key ... create ivan --gb 10
  RatnetVPN.exe --host 1.2.3.4 --key ... link ivan
  RatnetVPN.exe --host 1.2.3.4 --key ... block ivan
  RatnetVPN.exe --host 1.2.3.4 --key ... unblock ivan
  RatnetVPN.exe --host 1.2.3.4 --key ... delete ivan
