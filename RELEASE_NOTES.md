## Ratnet VPN 1.0 huyalfa

Портативная утилита для управления транзитным VPN: **вход в России + зарубежные выходы**.
Подключается к серверам по SSH, ставить на них ничего не нужно — только доступ.

### Что внутри

`RatnetVPN.exe` — один файл, Python и установка не требуются.
Рядом можно положить папку `scripts` со скриптами установки — тогда программа возьмёт их
оттуда (удобно править без пересборки), иначе использует встроенные.

Контрольная сумма:
```
SHA-256  4c0fbb04af51b49262b7b23741e1183afe7c10919d3b8bb7bfb0c0069b840a42
```

### Возможности

- **Серверы.** Слева российский вход, справа зарубежный выход: проверка связи,
  развёртывание входа (reality / tls / hysteria2), подготовка ноды, подключение
  её к балансировщику.
- **Клиенты.** Список с расходом и лимитами, создание профиля с готовой ссылкой,
  удаление, сброс лимита, блокировка и разблокировка (UUID при этом сохраняется).
- **Блокировка рекламы** на входе: кнопка «Переключить» и индикатор `вкл` / `выкл`,
  по умолчанию выключена.
- **Журнал** заполняется построчно по ходу выполнения, а не в конце операции.
- **Очистка сервера** — возврат в состояние «до Ratnet VPN» с предпросмотром,
  подтверждением и бэкапом в `/root`.
- **Буфер обмена**: Ctrl+V/C/X/A, правая кнопка мыши, копирование строк из журнала.

### Быстрый старт

1. Скачайте `RatnetVPN.exe`.
2. Вкладка «Серверы» → укажите IP входа, пользователя и ключ (или пароль) →
   «Проверить связь» → «Развернуть вход».
3. Справа укажите выход → «Подготовить ноду» → «Соединить с входом».
4. Вкладка «Клиенты» → «Создать клиента» → «Копировать ссылку» → вставить в клиент
   (Hiddify и т.п.).

Подробная инструкция — в `README.md` репозитория и в файле `ЧИТАЙ-МЕНЯ.txt`
внутри архива с программой.

### Важно

- Приложение подключается по SSH от `root`: оно меняет конфиги служб.
- Пароли и ключи не сохраняются на диск, живут только в памяти процесса.
- Хост-ключи серверов принимаются автоматически (как `StrictHostKeyChecking=no`).
- При транспорте `hysteria2` пофамильные лимиты и статистика на входе не работают:
  все клиенты приходят одним транзитным пользователем.
